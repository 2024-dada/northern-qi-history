# 北齐史料数据库

资料版本：20261112-primary-v1；检索版本：bm25-chunks-v1。来自识典古籍的公开古代原文录文，不采集现代译文，不绕过登录或付费限制。

## 本轮实际收录

- 22个篇章页面采集成功；1个与另一页仅卷题不同、正文完全相同，合并出处后保留21份原文。
- 245个不重复语义块；41条网站材料均有关键词定位的原文候选块。
- 网站两个答疑入口都用本地JavaScript BM25检索这245块；人物、主题、时间、书卷、原文分字段计算，不调用外部搜索服务。
- BM25前增加本地问题解析：识别列举、比较、原因、处置方式和正式法典问题，按有限词典扩展检索词；追问时可使用当前页面标题和最近一条用户问题。保留原问，不额外调用模型；界面展示检索意图与扩词。
- **候选关联不等于每条断言已经证实；影印、版本及逐断言核验仍待完成。**
- 范围包括《北齐书》《北史》《魏书》《资治通鉴》卷171、《史纠》卷3等相关篇章；不是这些书的全本或所有可能史料。
- 同页只收一份，多事件引用同一chunk_id；完全相同的块合并出处。近似异文保留，不当作多份独立见证。

## 更新流程

在项目根目录运行：

```powershell
python 02_史料数据库/工具/collect_sources.py
python 02_史料数据库/工具/build_corpus.py
```

采集会复用URL缓存；需要重新核对某页时，删除该页对应缓存再采集。网页读取失败会记录错误，不用AI补写。build从网站data.js/dossier.js导出事件卡，与已采集原文生成前端和后端资料副本；不改变密钥配置、不执行自动付费模型调用。

前端还需在website/ai-client运行node build.mjs；站长后端在ai-service运行node scripts/build.mjs，分别发布后才真正生效。

检索运行在浏览器与现有答疑Worker中，不需要注册BM25服务、Elasticsearch或购买数据库。检索本身没有额外账单；AI生成答案仍沿用DeepSeek API，并按原有模型用量计费。BM25改变材料召回方式，不保证史料候选已证实或模型回答必然正确。

BM25完整索引由`03_索引/原文切块.json`生成到`website/ai-client/search-index.js`和`ai-service/worker/search-index.js`。共享算法源码以`website/ai-client/bm25.js`为准；建库脚本会同步到Worker。问题解析/扩词也包含在共享算法中，不会增加模型调用。发布前分别构建前端SDK和站长Worker。当前尚未用人工标注评测集比较新旧召回率，因此不能宣称答案精度已实测提高。

## 本地与GitHub位置

本体在website/knowledge-base，由GitHub仓库跟踪。工作区根的02_史料数据库是指向本体的目录联接，便于直接打开，**不是第二份数据副本**。临时采集缓存与原始抓取结果不提交，只提交原文、块、规范和必要索引。
