# 原文语义块

郡陷，翟让，因为李密所得，密甚礼之，署为记室，军书羽檄，皆成其手。及密败，为王世充所杀。珽弟孝隐，亦有文学，早知名，词章虽不逮兄。亦机警有辩，兼解音律。魏末，为散骑常侍，迎梁使。时徐君房、庾信来聘，名誉甚高，魏朝闻而重之。接对者多取一时之秀，卢元景之徒，并降阶摄职，更递司宾。孝隐少处其中，物议称美。孝隐从父弟茂，颇有辞情，然好酒性率，不为时重。大宁中，以经学为本乡所荐，除给事，以疾辞，仍不复仕。珽受任寄，故令呼茂，茂不获已，暂来就之。珽欲为奏官，茂乃逃去。珽族弟崇儒，涉学有辞藻，少以干局知名。武平末，司州别驾、通直常侍，入周，为容昌郡太守。隋开皇初，终宕州长史。

北齐书卷三十九终。
