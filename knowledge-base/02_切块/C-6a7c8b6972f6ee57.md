# 原文语义块

时乐陵王百年为皇太子，肃宗以光世载醇谨，兼著勋王室，纳其长女为太子妃。大宁元年，除尚书右仆射，食中山郡干。二年，除太子太保。河清二年四月，光率步骑二万朵勋掌城于轵关西，仍筑长城二百里，置十三戍。三年正月，周遣将达奚成兴等来寇平阳，诏光率步骑二万御之。兴等闻而退走，光逐北，遂人其境，获二千余口而𮟃。其年三月，迁司徒。四月，率𮪍北讨突厥，获马千余疋。

是年冬，用文帝遣其柱国、大司马尉迟迥、齐国公宇文宪、柱国庸国公可叱雄等，众称十万寇洛阳，光率骑五万，驰往赴击，战于邙山。回等大败，光亲射雄杀之，斩捕首虏三千余级。迥、宪仅而获免，尽收其甲兵辎重，仍以死者积为京观。世祖幸洛阳，策勋班赏，迁太尉，又封冠军县公。先是，世祖命纳光第二女为太子妃，天统元年，拜为皇后。其年，光转大将军。三年六月，父丧去官。其月，诏起光及其弟羡，并复前任。秋，除太保，袭爵咸阳王，并袭第一领民酋长，别封武德郡公，徙食赵州干，迁太传。十二月，周遣将围洛阳，壅绝粮道。

武平元年正月，诏光率步𮪍三万讨之。军次定陇，周将张掖公宇文桀、中州刺史鿄士彦、开府司水大夫梁景兴等又屯鹿卢交道。光擐甲执锐，身先士卒，锋刃才交，桀众大溃，斩首二千余级。直到宜阳，与周齐国公宇文宪、申国公掩跋显敬相对。十旬，光置筑统关、丰化二城，以通宜阳之路。
