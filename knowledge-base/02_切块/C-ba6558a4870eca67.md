# 原文语义块

及讨定阳，士深在军，恐祸及，长恭闻之曰：“吾本无此意。”乃求小失，杖士深二十以安之。尝入朝而仆从尽散，唯有一人，长恭独还，无所谴罚。武成赏其功，命贾护为买妾二十人，唯受其一。有千金责券，临死日尽燔之。
