# 原文语义块

京再诉，王使监厨苍头薛丰洛杖之，曰：“更诉当杀尔。”京与其党六人谋作乱。时王居北城东柏堂莅政，以宠琅邪公主，欲其来往无所避忌，所有侍卫，皆出于外。太史启言宰辅星甚微，变不出一月。王曰：“小人新杖之，故吓我耳。”将欲受禅，与陈元康、崔季舒等屏斥左右，署拟百官。京将进食，王却谓诸人曰：“昨夜梦此奴斫我，宜杀却。”京闻之，置刀于盘，冒言进食。王怒曰：“我未索食，尔何遽来？”京挥刀曰：“来将杀汝！”王自投伤足，入于床下。贼党去床，因而见杀。先是讹言曰“软脱帽，床底喘”其言应矣。时太原公洋在城东双堂，入而讨贼，脔割京等，皆漆其头。秘不发丧，徐出言曰：“奴反，大将军被伤，无大苦也。”

帝纪第三     北齐书三
