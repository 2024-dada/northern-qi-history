# 原文语义块

显祖弱龄藏器，未有朝臣所知，及北宫之难，以年次推重，故受终之议，时未之许焉。杜弼识学甄明，发言谠正，禅代之际，先起异图，王怒未怠，卒蒙显戮。直言多矣，能无及是者乎！赞曰：彦举驱驰，才高行诐。元康忠勇，舍生存义。卬卬辅玄思极谈天。道亡时晦，身没名全。

列传第十六    北齐书二十四
