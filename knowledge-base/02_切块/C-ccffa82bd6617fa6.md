# 原文语义块

高隆之、高德政、杜弼、王元景、李蒨之等皆以非罪加害。尝在晋阳以槊戏刺都督尉子耀，应手即殒。又在三台大光殿上，以鐻鐻都督穆嵩，遂至于死。又尝幸开府暴显家，有都督韩哲无罪，忽于众中唤出斩之。自余酷滥，不可胜纪。朝野憯憎，各怀怨毒。而素以严断临下，加之默识强记，百僚战栗，不敢为非，文武近臣朝不谋夕。又多所营缮，百役繁兴，举国骚扰，公私劳弊。凡诸赏赉，无复节限，府藏之积，遂至空虚。自皇太后诸王及内外勋旧，愁惧危悚，计无所出。暨于末年，不能进食，唯数饮酒，曲蘖成灾，因而致毙。

论曰：高祖平定四胡，威权延世，迁邺之后，虽主器有人，号令所加，政皆自出。显祖因循鸿业，内外恊从，自朝及野，群心属望。东魏之地，举世乐推，曾未期月，玄运集已。始则存心政事，风化肃然，数年之间，翕斯致治。其后纵酒肆欲，事极猖狂，昏邪残暴，近世未有。飨国弗永，实由斯疾，胤嗣殄绝，固亦余殃者也。赞曰：天保定位，受终攸属。奄宅区夏，爰膺帝箓。势协讴歌，情毁龟玉。始存政术，闻斯德音。罔遵克念，乃肆其心。穷理残虐，尽性荒淫。

帝纪第四    北齐书四
