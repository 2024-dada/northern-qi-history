# 原文语义块



帝与绰临观，喜噱不已，谓绰曰：如此乐事，何不早驰驿奏闻。绰由是大为后主宠，拜大将军，朝夕同戏。韩长鸾间之，除齐州刺史。将发，长鸾令绰亲信诬告其反，奏云：此犯国法，不可赦。后主不忍显戮，使宠胡何猥萨后园，与绰相扑，扼杀之，瘗于兴圣佛寺。经四百余日，乃大敛，颜色毛发皆如生。俗云：五月五日生者，脑不坏。绰兄弟皆呼父为兄兄，嫡母为家家，乳母为姊姊，妇为妹妹。齐亡，妃郑氏为周武帝所幸，请葬绰，敕所司葬于永平陵北。

琅邪王俨，字仁威，武成第三子也。初封东平王，拜开府、侍中、中书监、京畿大都督、领军大将军，领御史中丞，迁大司徒、尚书令、大将军、录尚书事、大司马。魏氏旧制，中丞出，清道与皇太子分路行，王公皆遥住车去牛，顿轭于地，以待中丞过。其或迟违，则赤棒棒之。自都邺后，此仪浸绝。武成欲雄宠俨，乃使一依旧制。初从北宫出，将上中丞，凡京畿步骑、领军之官属，中丞之威仪，司徒之卤簿，莫不毕备。帝与胡后在华林园东门外张幕，隔青纱步障观之，遣中贵骤为趣仗，不得入，自言奉敕赤棒，应声碎其鞍，马惊人坠。帝大笑以为善，更敕令驻车传语。良久，观者倾京邑。俨恒在宫中，坐含光殿以视事，诸父皆拜焉。帝幸并州，俨常居守。每送驾或半路，或至晋阳乃还。

王师罗常从驾后至，武成欲罪之，辞曰：臣与第三子别，留连不觉晚。
