# 原文语义块

乃眷关右，实怀兼并之志，经谋宏远，寔当代之明主。而降年不永，其故何哉？岂幽显之间，实有报复？将齐之基宇止在于斯？帝欲大之，天不许也？ 

帝纪第六    北齐书六
