# 原文语义块

皇建初，封定阳郡公，拜护军，后为青州刺史，卒赠太尉。

款之至，成此大功，故能终享遐年，位高百辟。观其盈满之戒，动之微也。才及后嗣，遂至诛夷，虽为威权之重，盖符道家所忌。光以上将之子，有沈毅之姿，战术兵权，暗同韬略，临敌制胜，变化无方。自关河分隔，年将四纪。以高祖霸王之期，属宇文草创之日，出军薄伐，屡挫兵锋。而大宁以还，东邻侵弱关西，前收巴蜀，又殄江陵，叶建瓴而用武，成并吞之壮气。斛律治军誓众，式遏

边鄙，战则前无完阵，攻则罕有全城，齐氏必致拘

以震主之威；主暗时难，自毁藩篱之固。昔李牧之为赵将也，北翦胡𭁵，西却秦军，郭开譛之，牧死赵灭。其议诛光者，岂秦之反间欤？何同术而同亡也？内令诸将解体，外为强邻报雠，呜呼！后之君子，可为深戒。

赞曰：赳赳咸阳，邦家之光。明月忠壮，仍世将相。声振关右，势高时望。迫此威名，易兴说𮒲。始自口言，终斯交丧。

诵傅第九北齐书十七
