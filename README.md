# 帝怒之后 · 北齐高氏暴力的事件与叙述

> 中国历史概论 / 550—577

通过事件、关系图与史料对照，逐层探究北齐高氏暴力的原因。

## 项目简介

本项目以网页形式呈现北齐（550—577）高氏皇室的暴力事件研究。从一个人的死亡出发，沿着冲突、谗言与命令，走进北齐高氏暴力的层层叙述。

## 核心内容

- **动态档案**：六幅暴力方式的动态切片
- **循迹阅读**：四个核心事件的逐步展开
  1. 高洋与高德政 · 559年
  2. 高纬与斛律光 · 572年
  3. 高纬与高俨 · 571年
  4. 高洋与薛嫔 · 天保年间
- **自由探索**：10 个候选事件、4 位研究人物，支持按人物、时间、方式、分歧筛选
- **史料对照**：以识典古籍为主要入口，辅助在线录文用于定位与对照

## 史料来源

以识典古籍（shidianguji.com）为主要入口，引用《北齐书》《北史》《资治通鉴》等正史。

## 研究原则

- 先追过程，再判原因
- 逐案排序，区分主要原因、促成机制与背景条件
- 不同记载有分歧时展示分歧，不补成一个更好看的故事
- 不作现代精神疾病诊断，不推导某个族群的固有性格
